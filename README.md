# Gym Progress

Визуализация тренировок из CSV. Статическая страница без сборки.

- Обычная ссылка: загрузка своего CSV в браузере.
- `?u=ruslan`: загрузка опубликованного файла `data/ruslan.csv`.
- Параметр `u` выбирает данные, но не ограничивает доступ: файл и история тренировок публичны.

CSV должен содержать столбцы `Workout,Date,Exercise,Set,Reps,Weight (kg)`. Дата: `YYYY-MM-DD`.

Локальный запуск: `python3 -m http.server 4174 --directory public-site` из родительской папки, либо `python3 -m http.server 4174` из корня репозитория.

Публикация: GitHub Pages, ветка `main`, папка `/`.
